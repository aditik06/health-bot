# Fonts

Both typefaces are self-hosted here (no external font CDN) and licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org/), which permits bundling,
modification, and redistribution as part of this project.

- **Fraunces** (`fraunces-600.woff2`, `fraunces-500-italic.woff2`) — display headlines.
  By Undercase Type, distributed via [Google Fonts](https://fonts.google.com/specimen/Fraunces).
- **Plus Jakarta Sans** (`jakarta-variable.woff2`, variable weight 200–800) — body/UI text.
  By Tokotype, distributed via [Google Fonts](https://fonts.google.com/specimen/Plus+Jakarta+Sans).

Only the Latin subset is included, matching this app's copy.
